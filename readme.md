# Semester Project 2 - Auction Website

## Description
Semester Project 2 is a web application built with **Bootstrap** and **Vanilla JavaScript**. It is an **auction platform** where users can log in, create profiles, and participate in auctions. Users can place bids on items, and each auction has a countdown timer until it ends.

## Features
- **User Registration**: New users can create accounts and register with necessary details.
- **Login**: Users can log in to their account to access auctions and their profiles.
- **Auctions**: Users can view available auctions and place bids on items.
- **User Profile**: Each user has a profile where they can view their ongoing auctions and history.
- **Responsive Design**: The application is built with **Bootstrap** to ensure it works on both mobile and desktop devices.

## Technologies Used
- **HTML5** – For the structure of the pages.
- **CSS3** – For styling, including responsive design with **Bootstrap**.
- **JavaScript** – For interactivity and handling user interactions.
- **Bootstrap 4/5** – For responsive design and components.
- **LocalStorage** – For storing user data (such as login information) on the client-side.
